# ML Task — Particle Trajectories

Учебный проект по анализу табличных данных и классификации типов траекторий частиц с помощью методов машинного обучения. Основная задача ноутбука — по пяти числовым признакам определить один из трёх классов: `converging`, `diverging` или `oscillating`.

## Состав проекта

| Файл | Назначение |
|---|---|
| `ml.ipynb` | Jupyter Notebook: разведочный анализ, визуализация, обучение и сравнение моделей, подбор гиперпараметров |
| `particle_trajectories.csv` | Датасет из 20 000 наблюдений с признаками и целевой переменной `trajectory_type` |

## Данные

В CSV-файле содержатся следующие столбцы:

| Столбец | Тип | Описание |
|---|---|---|
| `x0` | числовой | Используется в ноутбуке как координата в фазовой диаграмме |
| `v0` | числовой | Используется в ноутбуке как скорость в фазовой диаграмме |
| `V0` | числовой | Дополнительный числовой признак |
| `x0_scale` | числовой | Дополнительный числовой признак |
| `gamma` | числовой | Дополнительный числовой признак |
| `trajectory_type` | категориальный | Целевой класс траектории: `converging`, `diverging` или `oscillating` |

В датасете 20 000 строк. Пропущенные значения и полные дубликаты при проверке CSV не обнаружены. Точные физические определения всех параметров и единицы измерения в материалах проекта явно не заданы, поэтому их не следует трактовать как установленные только по названиям столбцов.

Распределение целевого класса:

| Класс | Количество | Доля |
|---|---:|---:|
| `converging` | 7 423 | 37,12 % |
| `diverging` | 7 142 | 35,71 % |
| `oscillating` | 5 435 | 27,18 % |

## Что выполняется в ноутбуке

1. Загрузка и первичный анализ данных, оценка распределения классов.
2. Визуализация признаков, в том числе фазовой диаграммы `x0`–`v0`, boxplot-графиков и проекции PCA на две главные компоненты.
3. Кодирование целевых классов и стратифицированное разделение данных на обучающую и тестовую выборки в отношении 70/30 (`random_state=42`): 14 000 и 6 000 наблюдений соответственно.
4. Стандартизация признаков: параметры `StandardScaler` вычисляются на обучающей выборке и затем применяются к тестовой.
5. Обучение и сравнение трёх классификаторов:
   - Logistic Regression;
   - Random Forest Classifier;
   - Multi-layer Perceptron (MLP).
6. Подбор гиперпараметров с помощью `RandomizedSearchCV` и 5-кратной стратифицированной кросс-валидации.
7. Итоговая оценка моделей по Accuracy, Balanced Accuracy и macro-averaged F1-score, а также анализ матриц ошибок и границ решений.

## Результаты

Ниже приведены значения из итоговой таблицы ноутбука для моделей после подбора гиперпараметров. Метрики рассчитаны на тестовой выборке из 6 000 наблюдений.

| Модель | Accuracy | Balanced Accuracy | F1-macro |
|---|---:|---:|---:|
| Logistic Regression | 0,5138 | 0,4729 | 0,4158 |
| Random Forest | 0,9322 | 0,9285 | 0,9277 |
| MLP | **0,9542** | **0,9472** | **0,9502** |

Наилучший результат в сохранённых расчётах показала MLP-модель с двумя скрытыми слоями по 53 и 62 нейрона, функцией активации ReLU и оптимизатором Adam. Её Accuracy на тестовой выборке составляет 95,42 %, а macro F1-score — 0,9502.

Для справки: лучшие значения Accuracy на этапе 5-кратной кросс-валидации в поиске гиперпараметров составили 0,5203 для Logistic Regression, 0,9223 для Random Forest и 0,9584 для MLP. Это оценки на кросс-валидации, их не следует смешивать с итоговыми метриками на отдельной тестовой выборке.

## Запуск

1. Склонируйте репозиторий или скачайте его архивом.
2. Убедитесь, что `ml.ipynb` и `particle_trajectories.csv` находятся в одной папке.
3. Установите зависимости из раздела выше.
4. Запустите Jupyter и откройте ноутбук:

```bash
jupyter notebook ml.ipynb
```

В ноутбуке используется относительный путь `particle_trajectories.csv`, поэтому имя CSV-файла должно совпадать с указанным.
